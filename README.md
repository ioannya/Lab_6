Lab 6 — Refactoring 

Найденные проблемы (code smells)
- Длинная функция `process_checkout` (Long Function).
- Смешение разных задач в одной функции (валидация, расчёты, генерация id).
- Магические числа и строки (ставка налога, проценты скидок, пороги, коды купонов).

Применённые рефакторинги
- Extract Function: вынесены функции `validate_request`, `validate_items`, `calculate_subtotal`,
  `calculate_discount`, `apply_discount`, `calculate_tax`, `generate_order_id`.
- Introduce Constant: вынесены магические значения в именованные константы.

Что стало проще
- Код читается как сценарий сверху вниз.
- Проще менять правила скидок/налога и добавлять новые купоны.
- Проще тестировать и поддерживать отдельные части логики.
